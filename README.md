# Studio is my personal OS.

I'm replacing all the apps I use with diy versions. I've made these just for me. This is a personal project to explore my own mental space and express it with the aid of computing. 

Built with Claude code using Tauri in vanilla HTML, CSS and Javascript and some Swift helpers for MacOS.

This code isn't truly ready for anyone else to run yet. I'll clean it up in a few weeks. It might be more practical to extract the most useful apps so that people can easily run on their own machine without the Swift parts.
