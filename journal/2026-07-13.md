# 2026-07-13

- Big cleanup of how tool windows get opened and styled across the app: there's now a single code path for opening any tool window (tray icons, the tools menu, Spotlight, scheduled tasks, Git Pulse, Code Preview all go through it), one consistent way windows get their labels, and consistent rounded-corner/chrome styling everywhere. Fixed a latent bug where windows opened from Spotlight could get clamped too small.
- Added a new Server tool: a little window with an oscilloscope-style display to start/stop a project's dev server and see whether it's running, without needing to know its port.
- Video editor got several UX improvements: window styling to match the rest of the app, the ability to delete edits right from the Artifacts panel (and dropped some redundant delete buttons), rename-in-place for edits (replacing the old dropdown switcher), and the "+ → Video" action now always starts a fresh edit instead of reopening an old one.
- Some behind-the-scenes groundwork: pulled shared helpers (Tauri invoke/listen wrappers, a toast notification) into a common module so tools don't have to duplicate that logic, and retired some old migration shims that were no longer needed.
