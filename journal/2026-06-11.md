# 2026-06-11

- Replaced the old AGENTS.md with a trimmed CLAUDE.md and split out separate docs per feature, making it easier to find relevant info.
- The usage meter now refreshes automatically when you launch the Claude window.
- You can rename a chat session just by clicking its name in the sidebar.
- Sessions list now shows a context usage percentage so you can see how full a conversation is at a glance.
- Cleaned up project cards: removed the folder path clutter, made the icons bigger, and added a "last edited" date (shown as "Yesterday", "3 days ago", etc., falling back to a date after a week).
- Pulled the Claude chat out into its own standalone "Studio Claude" app so it keeps running even when the main app is rebuilt. Each chat now shows the project's name and animal sprite.
- Got the companion app to open a separate chat window per project, so you can have several open side by side. This took some untangling — it was deadlocking and occasionally making windows vanish. Root cause was a mix of leftover registrations from old builds confusing macOS about which app to launch, plus the windows being created the wrong way. All fixed and committed; it now reliably opens (or re-focuses) one window per project.
- Big new feature: **scheduled tasks**. You can now set up tasks that run automatically at set times. Highlights: each task gets its own time slot, tasks are global with a per-task project picker, they live in their own dedicated window, and there's a manual "save schedule" step so changes are deliberate. Added a Schedules button (including on the empty no-project screen) and a Scheduled Tasks entry in the menu-bar tray.
- To make schedules actually fire reliably, the Mac now stays awake while the app is open, and the app schedules a system wake-up ahead of upcoming tasks (rolling the wake time forward after each run). It only asks for your admin password when the wake schedule actually changes.
- Visual polish: per-project animal sprites now show on the Workspace badge and project cards, the working status bar animates a little red panda (and shows the current tool/step being run), and added a set of brighter jewel-tone note themes with better text contrast.
