# June 12, 2026

- **Built a Git companion for Studio.** You can now pop open a small, brightly-colored window for any project's code repo right from the Workspace. It shows the current branch, the files you've changed (click one to open it in your editor), a box to write a commit message and commit everything, and your last commit with an "undo" button. Each project picks its own window color from a set of bright swatches.
- **Made those Git windows stick around.** They remember their size and spot on screen, and they reopen automatically after the app restarts during development — even keeping a half-typed commit message — so they don't vanish every time the app rebuilds.
- **Cleaned up the Workspace repo card.** It's now bigger with a clearer pecking order: the folder path up top, then a tidy footer for choosing your editor and opening the Git window. Easier to tell what's important at a glance.
- **Wrote down a bigger idea for Workspace.** Spent time figuring out what Workspace is really *for* — it's meant to arrange your app windows nicely per project and work mode, and fix the mess that happens when you unplug from the monitor. Captured the concept (remember a different window layout for the monitor vs. the laptop, set up by just arranging things and hitting "save") as a design doc. Nothing built yet — just the plan.
- **Smaller tidies:** Daily Notes now toggles open/closed from its menu-bar icon, and the RAM/memory overview moved out of a pop-up into its own menu-bar tool.
