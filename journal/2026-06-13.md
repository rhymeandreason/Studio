# 2026-06-13

- Added a config file so the menu-bar icon order and icons can be customized, and updated the icons themselves.
- Documented an idea for hot-reloading the tray config later.
- Git windows now let you expand a previous commit to see which files it changed.
- Added a dev shortcut: Cmd+Option+click any element in the app to jump straight to its style rule in the editor.
- Notes: links typed into a note are now turned into clickable links as soon as you hit Enter, not just when you click away.
- Workspace cards got a visual cleanup: folders, files, the repo, and apps now show their name in big text up top, with the path/URL tucked underneath in smaller, muted text. URL cards just show the site's domain (e.g. "etsy.com").
- App cards now show the app's actual icon next to its name.
- The repo card always stays pinned at the top of the Workspace list.
- Fixed a sneaky bug: opening certain projects (ones with apps like BambuStudio or Blender configured) was silently launching those apps in the background — just from generating the icon preview. That's fixed now.
