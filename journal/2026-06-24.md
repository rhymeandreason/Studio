# 2026-06-24

- **New custom window chrome system**: windows can now drop the native title bar entirely for fully custom, rounded, decorationless chrome (no traffic lights, a custom close dot, drag strip, no window shadow). Rolled out to the main app window, File Directory, and Code Editor, with a migration guide written up so other tools can adopt it too.
- **Project color now themes the whole window**: a shared "on-tint" color system lets headers, chips, and hover states use alpha-based tints of the project's accent color instead of flat colors — applied to the main app header and Code Editor's card-based UI.
- **Code Editor visual redesign**: card-based layout on the tinted window, grouped icon buttons, a new two-icon view toggle (built as a reusable segmented icon-toggle component), and assorted cleanup (dropped some unused diff text, smoother stale-refresh animation).
- File Directory now highlights files modified in the last 24 hours, tinted to match the hover color.
