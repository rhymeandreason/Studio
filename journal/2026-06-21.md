# 2026-06-21

- **New Mode switcher**: Ctrl+Space brings up a big, keyboard-first overlay for jumping between projects and their saved window layouts (Modes) — flip between projects with arrow keys, Tab to record the current window setup into a Mode, and it remembers the last Mode you used per project (auto-applying the first one when you switch to a project). Spotlight got a matching visual redesign to feel like part of the same family. This has become my favorite feature and fits more of the aesthetic I'm hoping to go for.
- **Project accent color**: each project can now have its own color, set via swatches in the Mode switcher, which replaces the old per-repo Git window color — so the color now follows the project everywhere (Git windows, File Directory hover states) instead of being set per-repo.
- **New standalone Image Editor tool**: pulled the non-destructive image editor out into its own tool window (sharing code with the inline editor), with a narrower single-column layout, an actions menu, and a clean empty state when no image is open.
- Media lightbox got an actions "..." menu, narrower stacking, and a Reset Adjustments option.
- Smaller fixes: Workspace tab moved into a round icon button next to the folder-open icon; workspace cards now update their name immediately and auto-open the browse dialog when adding a card; HTML/CSS/Markdown workspace files now open in the Code Editor; File Directory hover backgrounds now tint with the project's accent color.
