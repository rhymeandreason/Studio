# 2026-06-17

- **Built out a full Code Editor tool** — new tool that shows the DOM tree of an HTML file alongside a live preview, with element-to-source scroll sync, hover outlines, syntax highlighting (via Prism), a git diff view with teal-colored changes and deletion markers, Prettify with undo support, soft-wrap toggle, and session persistence across reloads. The preview now lives in a separate floating window. The editor is also wired up as an "Open in" option when browsing repos from the Git window.

- **Theme editor polish** — improved layout, wider window, added a Brand Explorer font browser, swatch-chip color UI with a Coloris polaroid theme, and preset themes loaded from files with live refresh on save. Save is now manual (no auto-save). Presentation artifact cards in the Artifacts panel now preview the first slide.

- Fixed a race condition that was causing the Artifacts panel to render twice.
