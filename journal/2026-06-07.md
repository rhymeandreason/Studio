# 2026-06-07

- New "Edit in Photos" handoff: extended-background images can now be sent straight to Apple Photos with the edit panel auto-opened, after iterating on the automation a few times to get it reliable.
- Refined the Extend Background tool further — clearer fill options, stronger blur with grain for "Simple Fill," and support for transparent images.
- Added an experimental "Generate image" feature using Apple's Image Playground.
- Lots of UI cleanup: consistent modals (close on click-off), better file naming with resolution/size shown, a font selector for Notes, pinned tabs, a "new project" button, and the ability to delete projects.
- Notes got nicer too — links auto-turn into buttons, switched to a Bento grid layout, and notes can be drag-and-dropped to reorder. First pass at Note card themes.
