# 2026-06-20

- **New Spotlight-style launcher**: press Option+Space anywhere to bring up a floating search palette listing every tool and project — type to filter, arrows + Enter to open, click away or Escape to dismiss. Took a couple rounds to get the transparent floating-card look right (a stray native window shadow, then a clipped CSS shadow) before it looked clean. Claude and Git aren't in the list yet — noted as a follow-up since neither fits the current tools/projects data cleanly.
- Workspace improvements: added Script cards so you can run a project's launch scripts directly from a saved layout, Repo cards now auto-detect dev-open/dev-stop scripts for their Start/Stop buttons, a combined +/dropdown button for adding cards, and switching Modes now hides app windows instead of minimizing them.
- Added a tiny Modes tool that just has Play buttons for modes.
- Code Editor: can now toggle between viewing uncommitted changes and the last commit's diff, and persists scroll position/cursor selection across reloads.
- Smaller fixes: Daily Notes now saves to disk instead of browser storage (so it isn't wiped by a cache clear); fixed a File Directory bug that rendered things twice; sprites are hidden on the All Projects view; documented how to build a frameless window for future tools.
- Prototyped a Tab-switcher for different tools called "tools dock" in a separate branch. It just used iframes, which doesn't really work. It's interesting, but would need refactoring tools into Modules. Let's see where we can get to with the Modes first.
