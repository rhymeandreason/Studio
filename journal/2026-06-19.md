# 2026-06-19

- **Workspace Modes**: replaced the old "Launch" button with Modes — record a window layout (which apps are open, where), then replay it with one click ("Play"). Handles Studio's own windows (Claude, Schedules, Video, Code Editor, Git Pulse, tray tools) as well as other apps, reopening anything that got closed and hiding/minimizing the rest on Play. Modes can now be renamed, and cards show bigger buttons + a "Saved <when>" timestamp.
- **New File Directory tool**: a vertical file tree per project. Opens code files in the Code Editor, artifact JSON in their matching Studio tool, and plain HTML files in the browser; remembers which folders you had expanded, has a larger-text toggle, and a project picker when nothing's active yet.
- **Tools got their own menu-bar dropdown**: instead of being mixed into the main Studio tray menu, all tools (Scheduled Tasks, Video Editor, and everything in the tools folder) now live under their own hexagon icon in the menu bar. Docs updated to match.
- **Design system cleanup**: consolidated a bunch of one-off styles (toggles, chips, sliders, edit buttons, tabs) into the shared kit so every tool looks consistent; rolled kit.css into all tools (including Daily Notes); fixed a font regression back to Futura.
- Smaller fixes: Code Editor now supports Cmd+F find-in-file; Notes grid resizing is more reliable (switched to a ResizeObserver, fixed narrow-window stacking); main window can now resize down to 320px wide; a few crash/UI fixes in File Directory and window layout restore.
