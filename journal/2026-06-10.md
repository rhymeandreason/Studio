# Today's progress (2026-06-10)

- Built out a "Tools" feature in Studio — small built-in utilities (like the bento-grid tool) that now save their exports directly into your active project's folder. If no project is open, it'll just pop up a normal save dialog instead.
- Made selected project cards much easier to spot — they now highlight with a bold dark background.
- Added the memory/RAM display and modal.
- Added a daily journal feature so Claude can summarize the day's work automatically.
- Big one: built a first version of an in-app Claude chat window — you can now run Claude Code sessions right inside Studio instead of a separate terminal. Includes session history, renaming/deleting sessions, usage/quota bars, permission mode controls, a stop button to interrupt a response, and the ability to select and copy text from the chat.
- Polished that Claude window a lot through the day: browser-style tabs for switching between sessions, a full-height sidebar, click-the-title-to-rename, and it now remembers its window size/position and shows the project name in the title bar.
- Made the usage display smarter and more reliable — it shows the real account quota (5-hour bar plus a 7-day pie), a live "Claude is working…" progress bar with token counts, and it no longer goes blank when the quota check is briefly rate-limited. Also fixed the context meter that was wrongly reading over 100%.
- Tidied long conversations: tool steps now collapse to a single expandable line, and scrolling no longer yanks you to the bottom while you're reading earlier output.
- Reused the Notes page's dropdown style for the Claude controls so it feels consistent, and on the Notes page added a Bento/Days view toggle plus brighter card themes.
